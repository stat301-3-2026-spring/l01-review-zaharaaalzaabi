Question 6

When splitting the data, why is it useful to stratify by the outcome/target variable?

TipSolution

Stratifying by the target variable helps keep the same balance of outcomes in both the training and testing sets. This matters most when your data are imbalanced—meaning one class shows up far more often than the others. Without stratification, a random split might leave one set with too few examples of a certain class, which can make a model biased and its evaluation less trustworthy.

Question 7

Briefly describe how v-fold cross validation with repeats is used to estimate test RMSE. Also provide an explanation of why we use it.

TipSolution

in v-fold cross-validation, the data is split into v equal-sized folds. The model is trained on v − 1 folds and tested on the remaining fold, repeating this process so each fold is used as the test set once. With repeats, the entire process is performed multiple times using different random splits of the data. RMSE is calculated for each test fold across all repeats, and the average of these values is used as an estimate of test RMSE. v-fold cross-validation is used with repeats because it provides a more reliable and stable estimate of model performance than a single train-test split.

When might we use a bootstrap resampling procedure instead of v-fold cross validation to estimate test RMSE?

TipSolution

A bootsrap resampling is used when the dataset is small or when we want to better estimate the variability and uncertainty of model performance. Bootstrap repeatedly samples with replacement from the data, allowing us to assess how much the RMSE might vary across different samples.
